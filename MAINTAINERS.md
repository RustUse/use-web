# Maintainers

RustUse/use-web is maintained by the RustUse maintainers.

## Responsibilities

Maintainers are responsible for:

- reviewing and merging changes
- preserving the small-crate scope of the workspace
- keeping release automation and policy docs aligned with the repository state
- coordinating first-wave and follow-up crates.io publishes

## Contact routing

For support, security, and community policy, use the RustUse organization defaults linked from `CONTRIBUTING.md`.

Repository-specific release or scope questions should be raised in issues or discussions on the canonical GitHub repository.
